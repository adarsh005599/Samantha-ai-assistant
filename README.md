# Samantha AI Assistant

An AI-powered voice assistant built with FastAPI, SQLite, and LLM integrations for natural voice conversations.

## 🚀 Features

- AI-powered conversations
- Voice assistant backend
- FastAPI REST API
- SQLite database
- Appointment management
- Modular project structure

## 🛠️ Tech Stack

- Python
- FastAPI
- SQLite
- Uvicorn

## 📌 Status

🚧 Currently under development.

New features including speech-to-text, text-to-speech, memory, tool calling, and voice interactions are being added.
